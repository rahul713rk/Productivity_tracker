System Requirements

Operating System

Linux (Ubuntu 20.04+, Debian 11+, Fedora 36+, or any modern distro)

Display Server

X11 or Wayland (both supported natively)

Webcam

Any USB or built-in camera for face detection

Python

3.9 or later (only for building from source)

Installation

Option A — AppImage (Recommended)

The AppImage is a portable binary that runs on any Linux distribution. No installation required.

Terminal 
# Download the AppImage
wget https://github.com/rahul713rk/Productivity_tracker/releases/download/v1.1/ProductivityTracker-x86_64.AppImage

# Make it executable
chmod +x ProductivityTracker-x86_64.AppImage

# Run
./ProductivityTracker-x86_64.AppImage

Option B — DEB Package (Ubuntu / Debian)

Native package that integrates with your system's application menu.

Terminal 
# Download the DEB package
wget https://github.com/rahul713rk/Productivity_tracker/releases/download/v1.1/productivity-tracker_1.1_amd64.deb

# Install
sudo dpkg -i productivity-tracker_1.1_amd64.deb

# Fix any missing dependencies
sudo apt-get install -f

Option C — Build from Source

For developers or users on non-Debian distributions.

Terminal 
# Clone the repository
git clone https://github.com/rahul713rk/Productivity_tracker.git
cd Productivity_tracker

# Install system dependencies (Ubuntu/Debian)
sudo apt update
sudo apt install python3-venv libxcb-cursor0 libgl1-mesa-glx

# Create virtual environment
python3 -m venv venv
source venv/bin/activate

# Install Python dependencies
pip install -r requirements.txt

# Run
python main.py

First Run

Wayland Users — Activity tracking on Wayland requires your user to be in the input group. The app will prompt you on first launch, or you can run: sudo usermod -aG input $USER and then log out/in.

When you launch for the first time:

  1. Camera Permission — Your OS may ask for webcam access. Grant it so face detection can work.
  2. Home Tab Loads — You'll see the stopwatch (left) and TODO list (right). The camera feed starts automatically.
  3. Timer Auto-Starts — As soon as a face is detected in the camera feed, the productivity timer begins counting.
  4. Auto-Save — The app saves your session data every 10 minutes automatically.

Usage Guide

Home Tab — Timer & Tasks

The Home tab is split into two panels:

  • Left Panel (Stopwatch): Shows the running timer and live camera feed with face detection overlay. The timer pauses when you leave and resumes when you return.
  • Right Panel (TODO): A full task manager. Create tasks, assign categories, and drag them through Pending → Working → Completed statuses.

Dataset Tab — Analytics

View your historical productivity data:

  • Data View: Browse raw daily records in a filterable table.
  • Graph View: Toggle to interactive QtCharts visualizations showing trends over time (daily hours, activity patterns, weekly comparisons).
  • Use the left-side control panel to filter by date range, category, or metric.

Git Tab — Sync Setup

Configure automatic GitHub syncing:

  1. Enter your GitHub username, email, and personal access token (with repo scope).
  2. Specify the repository URL where logs should be pushed.
  3. Click Save. From now on, every time you close the app, a Markdown log is committed and pushed.
Tip: Create a dedicated private repository for your logs. This keeps your contribution graph active without cluttering your main projects.

GitHub Sync — In Depth

How It Works

When you close the application (and confirm the exit dialog):

  1. A Markdown file summarizing today's session is generated from your SQLite data.
  2. The app stages, commits, and pushes to your configured remote repository.
  3. A progress dialog shows the sync status — the app won't close until sync is done.

Creating a Personal Access Token

Steps
1. Go to GitHub → Settings → Developer Settings → Personal Access Tokens → Tokens (classic)
2. Click "Generate new token (classic)"
3. Set a descriptive note (e.g., "Productivity Tracker")
4. Select the "repo" scope (full control of private repos)
5. Generate and copy the token
6. Paste it into the Git tab in the application
Security: Your token is stored locally in ~/.config/productivity-tracker/. Never share or commit this file.

Troubleshooting

Camera feed shows black / "No camera detected"

  • Ensure your webcam is connected and not in use by another application.
  • Check permissions: ls -la /dev/video0 — your user should have read access.
  • Install v4l-utils and run v4l2-ctl --list-devices to verify the camera is detected.

Activity tracking doesn't work on Wayland

  • Run groups and confirm input is listed.
  • If not: sudo usermod -aG input $USER, then log out and back in.
  • Verify with cat /dev/input/event0 — you should see raw bytes when you press a key.

AppImage won't launch

  • Make sure FUSE is installed: sudo apt install libfuse2
  • Re-download the file — partial downloads are the most common cause.
  • Check for executable permission: chmod +x ProductivityTracker-x86_64.AppImage

GitHub sync fails on exit

  • Verify your token has repo scope.
  • Check that the repository URL is correct and accessible.
  • Look for error messages in the terminal if running from source.

"libxcb-cursor0 not found" on launch

  • Install the package: sudo apt install libxcb-cursor0
  • On Fedora: sudo dnf install xcb-util-cursor

FAQ

Is my webcam video recorded or stored?

No. Frames are processed in real-time for face detection only. No images, videos, or screenshots are ever saved to disk or sent anywhere.

Where is my data stored?

The app follows the XDG Base Directory Specification:

  • Config: ~/.config/productivity-tracker/
  • Data: ~/.local/share/productivity-tracker/
  • Cache: ~/.cache/productivity-tracker/

Can I use this without a webcam?

Yes. The timer won't auto-start/stop, but you can still use the TODO manager, dataset viewer, and GitHub sync features.

Does it work on macOS or Windows?

Currently, the app is Linux-only. The input tracking layer uses Linux-specific APIs (evdev for Wayland). X11 mode may work on macOS/Windows with modifications, but it's not tested or supported.

How do I uninstall?

AppImage: Just delete the .AppImage file.
DEB: sudo apt remove productivity-tracker
Data: Remove ~/.config/productivity-tracker/ and ~/.local/share/productivity-tracker/
